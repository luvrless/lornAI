Quickstart

Install the standard OpenAI client or make direct HTTP requests using your favorite language.

bash 
pip install openai
python 
from openai import OpenAI

client = OpenAI(
    base_url="https://lorn.lol/api/v1",
    api_key="lorn_sk_live_demo"
)

response = client.chat.completions.create(
    model="lorn-5.5-sovereign",
    messages=[
        {"role": "system", "content": "You are a world-class coding mentor."},
        {"role": "user", "content": "Write a clean debounce function in TypeScript."}
    ]
)

print(response.choices[0].message.content)

Authentication

Requests to the lornAI API require an Authorization header containing your Bearer API key.

HTTP Header 
Authorization: Bearer lorn_sk_live_your_secret_key

POST /api/v1/chat/completions

Generates a model response for the given chat conversation. Supports streaming server-sent events (SSE).

Request Body

Field Type Description
model string Model ID (e.g. lorn-5.5-sovereign, fabel-4-architect)
messages array Array of message objects with role and content
stream boolean Set to true for streaming SSE deltas
temperature number Sampling temperature between 0 and 1.2 (default 0.7)

POST /api/v1/images/generate

Programmatic generation of high-resolution visual art and imagery powered by Flux ultra models.

cURL 
curl -X POST https://lorn.lol/api/v1/images/generate \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer lorn_sk_live_demo" \
  -d '{"prompt": "A futuristic glass skyscraper in Tokyo at night, neon reflections", "size": "1024x1024"}'
